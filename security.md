# Security

This repository contains homework assignments and supporting code for CSE 3000. It is intended solely to be used by the student (me) and the instructor.

### Intended users
- Student (Mayank Surti)
- Instructor (Matthew Lamoureux)

### Risk of security threats
- Academic Integrity: Code and work in this repository can be falsely claimed by another individual as their own work. 
- Personal Information: Any inclusion of personal information (such as email, ID) could result in privacy concerns

### Steps taken to secure the repository
- CODEOWNERS file: Dictates who maintains the code
- gitignore file: Prevents commitment of environment variables or system-specific files
- Rules for committing: Branches are created for assignments to ensure organization
